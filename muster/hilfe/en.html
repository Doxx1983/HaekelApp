What the Pattern Collection does

Keep your crochet patterns in one place: photos, PDFs, Word files and texts. Tags, search and favourites help you find them again quickly.

Adding patterns

Tap + Pattern at the bottom right:

  • Add file: images, PDFs, Word (.docx, .doc), LibreOffice (.odt) and text files (.txt). You can pick several at once. On a computer you can also drag files onto the page.
  • Paste text: enter a name and the pattern text, then Save. Without a name, the first line becomes the name.

The app takes the name from the file name. You can change it afterwards.

Organising

Tap a pattern to open it. There you can:

  • change the name,
  • add tags, e.g. “Amigurumi” or “Gift”: type and confirm with Enter or a comma. Tags you already use are suggested. × removes a tag.
  • keep notes, e.g. yarn, hook size or source,
  • mark a pattern with ☆ Favourite.

Patterns from the Grid Maker also have Open in Grid Maker: edit the chart there, and Update in collection then changes exactly this pattern.

Changes are saved straight away. ‹ Back (or your phone’s back button) returns to the overview.

Finding

  • Search: finds names, tags, notes and also the text inside text, Word and ODT files. With several words, all must appear.
  • Tags: tap tags in the bar to filter. With several tags, all must match. The number shows how many patterns have the tag.
  • ★ Favourites shows only your favourites.
  • Newest ⇅ switches the sort order between newest first and A–Z.

Viewing and using

  • Images are shown large, Open image shows them in a separate window.
  • PDFs appear directly in the app on a computer, on a phone via Open PDF.
  • Texts, Word and ODT are shown as text. Old .doc files are only stored; please download them to view.
  • Open in Ruler (for images and PDFs) shows the pattern in the Ruler, which marks the current row and counts along.
  • Open in Crochet Helper (for patterns with text, including PDFs with text) starts the pattern as a project in the Crochet Helper. If it is already a project there, you continue with your progress. In the Crochet Helper you can also pick text patterns directly under “Projects”.
  • Download saves the file back to your device, Delete removes the pattern after asking.

Backup

Patterns are stored only in this browser on this device. So nothing gets lost when you clear the browser storage or change devices:

  • The backup icon at the top right (arrow down) → Back up everything (all apps) saves all patterns plus projects, counters and grid in one file (isadody-backup-date.json). The same works on the start page.
  • Restore backup brings everything back from such a file, e.g. on a new device. What is already there stays; for projects and counters the most recently used state wins, for patterns the most recently changed version. The Crochet Helper has room for 10 projects; anything that doesn’t fit is listed in the message. Older files (muster-sicherung-…) work too.
  • The app checks the file and only takes what it knows. Still, only restore your own backups.

Please do not share purchased patterns, not even as a backup file.
