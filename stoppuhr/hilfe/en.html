What the stopwatch does

It measures how long you crochet on a project. Times add up per project. With an hourly rate it works out the labour cost at the end, e.g. for a selling price.

The projects are those from the Crochet Helper. If there are none yet, create a project there first.

Tracking time

  • Tap the project at the top. The list shows the time so far for each project and, if saved, the cost.
  • Start runs the clock, Stop pauses it. The next start continues counting.
  • The clock keeps running when you close the app or lock your phone.
  • Only one clock runs at a time: starting another project pauses the previous one.
  • Change time: enter the total time by hand, as h:mm (3:45) or in minutes (225). Handy if you forgot to stop.
  • Set to 0 deletes the measured time of the project.

Hourly rate

Optional. Enter what an hour of work is worth to you, e.g. 12.50. Each project has its own rate.

Labour cost

With an hourly rate, the stopwatch shows the cost as it runs: measured time, charged time, hourly rate and amount.

  • Round time to: exact, 10 minutes, quarter hour, half hour or full hour.
  • Round amount to: exact (cents), 5 cents, 10 cents, 50 cents or whole euros.
  • Rounding: standard rounds to the nearest step (3:07 → 3:00 with quarter hours), always round up counts every started step (3:07 → 3:15).
  • Save cost stores the amount with the project, with date, charged time and hourly rate. If the clock is still running, it is paused first. A new value replaces the old one after asking.

The app remembers the rounding for all projects.

Saving

Times, hourly rates and saved costs are stored in this browser on this device. If a project is deleted in the Crochet Helper, it also disappears from the list here.

You can back up everything on the start page under Back up your data. If the last backup was more than 14 days ago, every app reminds you.
